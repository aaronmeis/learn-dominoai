Block 1: Core concepts

Block 1 — Core concepts. Vocabulary from zero, then Domino terms.

Time: 60 minutes
Goal: Lock vocabulary before any vendor tour
Pack: Domino Data Lab (dominoai)

Focus

Define these without Domino first: model, training vs inference, experiment, registry, serving / endpoint, MLOps, governance, lineage, reproducibility, audit trail, Kubernetes (cluster, pod, image). Then Domino: Project, Workspace, Environment, hardware tier, Dataset, Job, model registry, model card, Model API, App.

Sources

  • source-ledger [S1] overview, [S2] architecture, [S4] registry, [S5] Environments, [S6] develop/train

Actions

  1. Write one sentence each for the zero-prior list. No Domino words yet.
  2. Open [S1] and [S6]. Map each Domino term onto one sentence from step 1.
  3. Mark three terms you cannot yet explain. They become glossary rows after the block.

Retrieval check

Question

What is a Project, and how is a Workspace different from an Environment?

%% fold answer after attempt %%

Answer cues

Project = unit of work. Workspace = hosted IDE on a hardware tier [S6]. Environment = the Docker image that IDE boots [S5].

Exit criteria

  • Zero-prior list written in your own words
  • Project / Workspace / Environment / hardware tier distinguished
  • Three weak terms listed for the glossary
