Block 3: Active practice

Block 3 — Active practice. Paper lifecycle sketch. No tenant.

Time: 90 minutes
Goal: Produce the sketch you will defend
Pack: Domino Data Lab (dominoai)

Focus

On paper (or a vault canvas): Project → Workspace / Job → Experiment → Registry → Endpoint or App. Annotate where compute runs and what is recorded. From official docs, label one page as architecture and one page as a compliance claim.

Sources

  • [S2] architecture, [S4] registry, [S6] train, [S7] deploy, [S8] Apps, [S10] marketing (claim, not contract)

Actions

  1. Draw the lifecycle. Boxes: Project, Workspace, Job, Experiment, model card, Model API, App.
  2. On each box, write plane (control / data / either) and record (what lands on the card or in metadata).
  3. Open [S2] and [S10]. Write "architecture" on one URL and "claim" on the other.
  4. Optional: from [S4], list model-card fields you can see without a tenant (starts E1A).

Retrieval check

Question

Where does a Streamlit App run, and what port must it serve?

%% fold answer after attempt %%

Answer cues

Data plane pod, hardware tier may target a plane. Port 8888 [S8].

Exit criteria

  • Annotated lifecycle sketch
  • One architecture URL and one claim URL labeled
  • Endpoint vs App distinguished
