GLOSSARY — Domino Data Lab (Enterprise AI Platform)

Study glossary for the Domino Data Lab pack. Terms and acronyms with expansions. Definitions follow the source ledger.

Definitions below are study definitions tied to the source ledger. The one-day session has not been sat, so none of these are marked as earned in practice. Acronyms are expanded in the Expansion column. NotebookLM supplied extra rows; the ledger wins where they differ.

See also the reviewed NotebookLM table: Glossary table.

Unity Catalog Unity Catalog Competitors A governance and data catalog product specific to the Databricks ecosystem. nearby work / external vendor feature

IL5 DoD Impact Level 5 Compliance DoD Impact Level 5. Marketing says Domino is deployed in DoD IL5 environments. That sentence is not a DISA PA or an ATO. Vendor claim, not a DISA PA. [S10]
ISO 27001 International Organization for Standardization 27001 Compliance International specification standard for establishing an Information Security Management System (ISMS). Program claim. [S10]
ISO 9001 ISO 9001 Compliance Quality-management standard. Program claim, not a certificate for this lab. [S10] Program claim. [S10]
JWT JSON Web Token Compliance JSON Web Token. Identity tokens the control plane can issue or consume. This pack has no tenant config. none

SOC 2 Service Organization Control 2 Compliance An auditing standard for managing customer data based on security, availability, processing integrity, confidentiality, and privacy. Program claim on the product home, not evidence for this lab. [S10]
CLI Command-line interface Hybrid Command-Line Interface; client tool allowing users to interact with Domino programmatically. Dataset CLI stays local in hybrid configurations
Control plane Control plane Hybrid UI, API, metadata, orchestration. Secrets Vault, Identity, Mongo/Postgres, Experiment Manager, Image Builder, Model Registry. The GPU does not live here. [S2] Does not directly run heavy compute workloads; those execute on the data plane.
Data plane Data plane Hybrid Where work runs: agent, autoscaler, Workspaces, Apps, endpoints, Jobs as ephemeral pods. [S2] Can be separated into Dev/Staging/Prod or split geographically via Nexus.
Data plane agent Data plane agent Hybrid Process on a data plane that talks to the control plane and starts work. [S2] none
Environment Image Builder Environment Image Builder Hybrid Control-plane service that builds Environment images. [S2] none
Identity Identity Hybrid Control-plane identity and access. SSO and Keycloak live here. [S2] none
Keycloak Keycloak Hybrid Open-source identity server. Domino can use it on the control plane. [S2] none
Local data plane Local data plane Hybrid Data plane in the control-plane cluster. Historically the full feature set. [S3] none
Nexus Domino Nexus Hybrid Hybrid: one control plane, many data planes. Optional add-on. Prefer the architecture page over the product page. Remote gaps: Starburst sources and Dataset CLI. [S3] [S21]
Remote data plane Remote data plane Hybrid Data plane in another cluster, cloud, region, or on-prem. Compute next to data that cannot move. Feature set is version-specific. [S3] [S21]
Secrets Vault Secrets Vault Hybrid Control-plane store for credentials. The GPU does not live here. [S2] none
AKS Azure Kubernetes Service Kubernetes Azure Kubernetes Service. One place a data plane can run. none
Cluster Cluster Kubernetes A Kubernetes cluster. The control plane and each data plane occupy one. none
CRD Custom Resource Definition Kubernetes Custom Resource Definition. Kubeflow uses these; Domino does not require you to operate them. [S42] none
EKS Elastic Kubernetes Service Kubernetes Amazon Elastic Kubernetes Service. One place a data plane can run. none
GKE Google Kubernetes Engine Kubernetes Google Kubernetes Engine. One place a data plane can run. none
Helm Helm (Kubernetes package manager) Kubernetes Kubernetes package manager. Domino is installed with Helm. [S2] none
HPA Horizontal Pod Autoscaler Kubernetes Horizontal Pod Autoscaler. Scales pods by load. Data-plane autoscaling is this family. [S2] none
Image Image Kubernetes Container image. An Environment is this abstraction. [S5] none
K8s Kubernetes Kubernetes Short for Kubernetes. Cluster that schedules pods from images. [S2] none
Kubernetes Kubernetes Kubernetes Cluster that schedules pods from images. Domino is Kubernetes-native (Helm). [S2] none
Pod Pod Kubernetes Ephemeral containers. Workspaces, Jobs, Apps, and endpoints run as pods. [S2] none
Dataset Dataset Lifecycle Versioned data Domino tracks for a Project. Remote Datasets exist since 6.0. Starburst sources and Dataset CLI stay on the local plane. Version-specific. [S3] [S23]
DME Domino Minimal Environment Lifecycle Domino Minimal Environment. A thinner Environment image. [S5] none
DSE Domino Standard Environment Lifecycle Domino Standard Environment. A stock Environment image. [S5] none
Environment revision Environment revision Lifecycle A rebuild of that image after an edit. The card should name the revision that trained the model. [S4] [S5] none
Experiment Experiment Lifecycle A tracked training execution record capturing code, environment, parameters, and results. Tracking files without pinning the environment and data leads to reproducibility theater.
Experiment tracking Experiment tracking Lifecycle Recording parameters and metrics for a run. Domino's Experiment Manager is MLflow-based. [S4] [S24] none
Hardware tier Hardware tier Lifecycle A configurable compute profile specifying CPU, memory, and GPU allocations assigned to a container run. Hardware tiers can target specific data planes in hybrid configurations.
Job Job Lifecycle Non-interactive run of Project code on a hardware tier. [S6] none
MLflow MLflow Lifecycle Open-source experiment and registry stack. Domino's Experiment Manager and model registry are MLflow-based. Chen et al. 2020 is nearby work, not a Domino eval. [S4] [S14] [S41] nearby paper / third-party tool
MLOps Machine Learning Operations Lifecycle Taking models from a notebook into a governed, repeatable lifecycle. Nearby papers are not a Domino eval. [S14] none
Model Model Lifecycle A machine learning artifact developed, registered, and deployed within the platform. Exporting a model artifact to another service does not replicate the full platform functionality.
Model registry Model registry Lifecycle A centralized control-plane repository for storing, versioning, and reviewing trained model artifacts and metadata. If an organization already uses Unity Catalog as their primary registry, avoid introducing a secondary registry.
Project Project Lifecycle The unit of work. Files, Environments, datasets, experiments, models, and Apps live here. [S1] none
RStudio RStudio Lifecycle IDE for R. One Workspace option. [S6] none
Training Training Lifecycle Fitting parameters on data. Usually a Job or a Workspace session. none
UI User Interface Lifecycle The control-plane web interface. Metadata lives here; GPUs do not. [S2] none
VS Code Visual Studio Code Lifecycle Visual Studio Code. One Workspace option. [S6] none
Workspace Workspace Lifecycle Hosted IDE (Jupyter, JupyterLab, VS Code, RStudio, SAS, MATLAB, Cursor) on a hardware tier. [S6] Leaving open on GPU tier causes idle GPU waste
Domino Data Lab Domino Data Lab Placement Enterprise AI / MLOps platform: workspaces, compute, datasets, experiments, registry, endpoints, Apps, governance. Docs are the contract. Homepage percentages and IL5 wording are briefing lines. [S1] [S10]
Environment Environment Placement Docker-image abstraction. Every Workspace, Job, App, and Model boots a container. [S5] Must be pinned alongside data and parameters to achieve true reproducibility.
GPU Graphics Processing Unit Placement Hardware accelerator card selected via specific hardware tiers for compute-intensive models. Leaving GPU workspaces running idle will quickly exhaust compute budgets.
IDE Integrated Development Environment Placement Interactive coding interface (e.g., Jupyter, VS Code) hosted within a workspace pod. The platform hosts IDEs, but the system of record lives in the platform, not the IDE.
Jupyter Jupyter Placement An interactive notebook environment hosted within Domino Workspaces. Hosted Jupyter alone is not the product without model cards
SaaS Software as a Service Placement A fully managed cloud deployment offering where Domino hosts and maintains the control plane instance. SaaS availability varies by regulatory and security tier requirement.
VPC Virtual Private Cloud Placement Isolated cloud network. A data plane or SaaS control plane can sit in one. [S9] none
API Application Programming Interface Serving Programmatic interface. Control-plane API and Model API are different objects. [S2] [S7] none
App Application Serving HTTP app (Dash, Flask, Streamlit, Shiny, or any HTTP) served from a Project on port 8888. Remote Apps since 5.9. Must serve on port 8888. [S8] [S22]
App Hub App Hub Serving A centralized platform catalog for sharing and scaling published interactive web applications to business users. Focuses on application delivery rather than model governance and building.
Dash Dash Serving Python web framework. Host it as a Domino App on port 8888. [S8] none
Endpoint Endpoint Serving A network-accessible address exposing a Model API or application running on a data plane pod. Must be clearly distinguished from web application deployments during architecture design.
Flask Flask Serving Python web framework. Model APIs package Flask; Apps can too. [S7] [S8] none
HTTP Hypertext Transfer Protocol Serving The protocol Apps and Model APIs speak. none
Inference Inference Serving Running a trained model on new inputs. Serving is inference as an endpoint or an App. none
Launchpad Launchpad Serving Where users find published Apps. [S8] none
Model API Model Application Programming Interface Serving Project files packaged as Flask (Python) or Plumber (R) and hosted as an endpoint. Remote Model APIs since 5.9. Check the installed version. [S7] [S22]
Plumber Plumber Serving R package that turns scripts into HTTP APIs. Model APIs can use it. [S7] none
port 8888 port 8888 Serving The required internal network port that interactive web applications must serve from within their data plane pod. Applications configured on alternate internal ports will fail health checks.
REST Representational State Transfer Serving HTTP API style. Model APIs are this shape. none
Serving Serving Serving Offering a model or App for others to call. Model API or App. [S7] [S8] none
Shiny Shiny Serving R web framework. Host it as a Domino App on port 8888. [S8] none
Streamlit Streamlit Serving Python web framework for rapid data application development hosted as a Domino App running on data plane pods. Must bind and serve on internal port 8888.
Any-tool claim Any-tool claim Trust Domino hosts many IDEs and frameworks. Hosting is not zero lock-in. Debate 2. Export the artifact. Metadata stores stay. [S1] [S5]
Briefing percentages Briefing percentages Trust 50% lifecycle, 6x development, 40% infra, 75% onboarding on the product home. Not an SLA. Briefing lines. Debate 4. [S10]
Governance Governance Trust The frameworks, policy checks, and visibility tools used to enforce compliance and security across assets. Compliance documentation reflects platform capabilities, not an automatic grant of authority to operate.
HITL Human in the Loop Trust Human in the loop. A person must approve before the next step. Model Sentry is the pack's example. [S7] none
Idle GPU Idle GPU Trust A Workspace left open on a GPU tier. Someone's budget. Trap, not a vendor claim. [S6]
Lineage Lineage Trust What produced this artifact. Model cards store it. [S4] none
Model card Model card Trust Lineage record: code, Environment, workspace settings, datasets. Reconstruct the run from the card. [S4] none
Model Monitoring Model Monitoring Trust Watching a live model after deploy. Named on the deploy pages; this pack has no tenant dashboard. [S7] [S26] none
Model Sentry Model Sentry Trust Human-in-the-loop review before production. [S7] none
Reproducibility Reproducibility Trust The capability to reconstruct and execute an exact historical run by locking environment, data, code, and seeds. Failing to pin environments and data yields superficial reproducibility.
Reproducibility Engine Reproducibility Engine Trust Domino's separate record of files and run context. Distinct from an MLflow experiment. No MLflow call means no experiment and no card lineage. [S25] [S24] none
Reproducibility theater Reproducibility theater Trust Tracking files without pinning Environment revision and data version. Trap. Pin Environment and data. [S5] [S4]
System of record System of record Trust Code plus Environment plus hardware plus datasets plus parameters that reconstruct a run. Debate 1. The reconstructable unit is the model card. [S4]
TEI Total Economic Impact Trust Forrester TEI of Domino in a 2021 press release (542% ROI). Not this pack's SLA. Press, not a contract. [S19]
