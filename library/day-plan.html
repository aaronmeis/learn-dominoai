Plan

Day plan — Domino Data Lab (Enterprise AI Platform)

Timed schedule for the seven pedagogy blocks. Human gate before W8 spend.

Focus total: ~350 minutes (~5.8h) plus breaks. Working fluency, zero prior, explain-and-sketch. No tenant.

Order Block Minutes Exit criteria
1 Core concepts 60 Define model, train/infer, experiment, registry, serving, MLOps, governance, Kubernetes at outline, then Project / Workspace / Environment in your own sentences.
2 Mental models 45 Sketch control plane vs data plane. State the system-of-record claim. Name one job each competitor wins.
3 Active practice 90 One annotated lifecycle: Project → Workspace / Job → Experiment → Registry → Endpoint or App, with compute location and recorded fields.
4 Teach it 30 Five-minute talk to a laptop-notebook person: SoR is the product; one job Domino should refuse.
5 Edge cases 45 Name four traps: reproducibility theater, idle GPU, lock-in vs any-tool, IL5 ≠ ATO.
6 Spaced review 20 Quiz bank without notes. Misses become glossary or quiz rows.
7 Application 60 Written explanation from zero plus the defended sketch plus one named failure mode.

Breaks

  • After block 3 (practice): 15–20m
  • After block 5 (edge cases): 10m

Human gate

W8 (nlm) waits until this plan is reviewed. Prep files can exist. Execute is a separate GO.

Falsifier

A feature tour that never names system of record, control plane vs data plane, or when another platform is better.
