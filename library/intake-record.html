Intake — Domino Data Lab (Enterprise AI Platform)

Date: 2026-10-11
Mode: A (mind map provided)

Mission snapshot

  • Outcome: By the end of the day, explain Domino Data Lab from zero and sketch one governed model lifecycle you could defend in a design review. The sketch names what a project contains, where compute runs, where the system of record lives, and when Databricks, SageMaker, OpenShift AI, Kubeflow, or Dataiku is the better placement. Success is a short written explanation plus that sketch, with one named failure mode.
  • Audience: Self-study. Own fluency so Aaron can place Domino in an architecture conversation. Not an exam and not a customer deliverable today. The teach-it block is practice for that conversation.
  • Depth: Working fluency across the platform, not a survey of every UI click and not a single-subsystem deep dive. Enough to sketch a project → experiment → registry → endpoint or App Hub path and say why the platform claims that path is reproducible. A later day can go deep on one slice (App Hub, hybrid control plane, or IL5).
  • Constraints: Eight hours available. The pack's focused blocks are about 5.5 hours. Extra time is source reading. Prefer official docs (domino.ai), at least one primary architecture or security page, and at least two named talks. Default competitor set for debates: Databricks, SageMaker, OpenShift AI, Kubeflow, Dataiku. Elicit light is required. No cluster build and no tenant lab is required.

This agent: intake through research-craft, W8 prepare, vault-file after downloads exist, and learn-dominoai. NotebookLM execute waits on nlm login (this agent does not run W8 unless asked later). All video renders go to another agent.

Falsification check

The day is a waste if it is a feature tour of workspaces and App Hub that never says how a system of record, reproducibility, and hybrid control-plane versus data-plane change a placement, and never names when Databricks, SageMaker, OpenShift AI, Kubeflow, or Dataiku is the better tool. Vendor speed or cost percentages (50% lifecycle, 6× faster, 40% infra) are briefing lines until measured or qualified. An IL5 or compliance logo is not an ATO.
