Block 2: Mental models

Block 2 — Mental models. Planes, system of record, hybrid, competitors.

Time: 45 minutes
Goal: Named models you can apply
Pack: Domino Data Lab (dominoai)

Focus

  • System of record: code + data + Environment + parameters reconstruct the run [S4]
  • Control plane vs data plane [S2]
  • Hybrid / Nexus: same Project story, compute moves to the data [S3]
  • Model factory vs App Hub: build/govern vs scale apps to users [S8] [S10]
  • "Any tool" is a claim: the platform hosts IDEs; it does not erase their semantics [S1]
  • Comparison set: Databricks, SageMaker, OpenShift AI, Kubeflow, Dataiku

Sources

  • [S2] architecture, [S3] Nexus, [S4] registry, [S12] Elprin, [S13] Vawdrey, CLAIMS-AND-DEBATES

Actions

  1. Draw two boxes: control plane (what is recorded) and data plane (what runs).
  2. For each competitor, write one job it wins.
  3. Read Debate 1 warrant. Write it as If X, then Y.
