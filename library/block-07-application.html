Block 7: Application

Block 7 — Application. Written explanation plus defended sketch.

Time: 60 minutes
Goal: The artifact a design-review room could hear
Pack: Domino Data Lab (dominoai)

Focus

Written explanation from zero, plus one defended lifecycle sketch. The sketch names Project contents, compute, system of record, and the tool you would not pick. Name one failure mode (reproducibility gap, cost, wrong platform, or compliance overclaim).

Sources

  • Your block 3 sketch, MISSION, CLAIMS-AND-DEBATES, cheatsheet

Actions

  1. Write 400–600 words from zero. No tenant screenshots.
  2. Attach the sketch. Annotate planes and recorded fields.
  3. One paragraph: the competitor that wins this job, with warrant.
  4. One paragraph: the failure mode you would watch in year one.
  5. File the write-up under learning-records/ when the day is sat.

Retrieval check

Question

What is the day's falsifier?

Answer cues

A feature tour that never names system of record, control plane vs data plane, or when another platform is better.

Exit criteria

  • Written explanation
  • Defended sketch
  • Named refusal and named failure mode
