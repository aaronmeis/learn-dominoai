Block 5: Edge cases

Block 5 — Edge cases. Traps that fail a design review.

Time: 45 minutes
Goal: Name the traps
Pack: Domino Data Lab (dominoai)

Focus

  • Reproducibility theater: tracking files without pinning Environment and data
  • Idle GPU / hardware-tier cost while a workspace sits open
  • "Any tool, no lock-in" versus the platform as the place work actually lives
  • Exporting a model does not make SageMaker / Snowflake / Databricks into Domino
  • IL5 / HIPAA / SOC 2 / 21 CFR Part 11 pages are a program, not an authorization for this lab
  • Vendor percentages are briefing lines, not an SLA
  • Remote Nexus planes may lack local-plane features [S3]

Sources

  • [S3] Nexus, [S5] Environments, [S7] deploy, [S10] marketing, elicit-light-research, Debates 2–5

Actions

  1. For each trap: tell, root cause, fix. Use the cheatsheet table.
  2. Write one sentence: "deployed in DoD IL5 environments" is not a PA.
  3. Write one sentence: Elicit found no Domino product paper.

Retrieval check

Question

What would make the IL5 sentence into something a design review can accept?

%% fold answer after attempt %%

Answer cues

A primary DISA PA or FedRAMP page for a named offering, plus this program's ATO. E3A still unrun.

Exit criteria

  • Four traps with tell / fix
  • IL5 and percentages qualified
  • Remote-plane gap named as version-check, not folklore
