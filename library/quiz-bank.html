Quiz bank mirrored on the Learn Domino AI console.

# Section Question Answer Source
1 Placement What is Domino's unit of work? A Project. Files, Environments, datasets, experiments, models, and Apps live there. [S1]
2 Placement What is a Workspace? A hosted IDE (Jupyter, VS Code, RStudio, and others) on a hardware tier. [S6]
3 Engine What is an Environment? A Docker-image abstraction. Every Workspace, Job, App, and Model boots a container. [S5]
4 Engine Where does the control plane live versus the data plane? Control plane: UI, API, metadata, orchestration. Data plane: Workspaces, Jobs, Apps, endpoints as ephemeral pods. [S2]
5 Engine What does a model card record? Lineage: code, Environment, workspace settings, datasets. [S4]
6 Engine What is Domino's model registry based on? MLflow. Chen 2020 is the nearby paper, not a Domino eval. [S4] [S14]
7 Limits What is Nexus? One control plane plus many data planes. Optional. Remote planes may lack features the local plane has. [S3]
8 Limits Is "deployed in DoD IL5 environments" an ATO? No. It is a marketing sentence. A PA or ATO is a named authorization for a named offering. [S10]
9 Limits What are 50% / 6× / 40% / 75%? Briefing lines on the platform page. Not an SLA. [S10]
10 Placement When is Databricks the better placement? When the work already lives on that lakehouse and Unity Catalog is the system of record. Debate 5
11 Engine What port must a Domino App serve? 8888. [S8]
12 Engine How is a Model API packaged? Flask for Python, Plumber for R, from Project files. [S7]
13 Limits What did Elicit return for a Domino product paper? Nothing. Nearby MLflow and reproducibility papers only. E3B
14 Engine What is Model Sentry? Human-in-the-loop review before production. [S7]
15 Placement Name three deployment offerings. Managed SaaS, self-managed VPC, on-prem. Nexus data planes are optional. [S9]
16 Engine What is Launchpad? The catalog where users find published Apps. [S8]
17 Limits What historically did remote data planes lack? Model APIs, Apps, Datasets, Starburst. Check the installed 6.2 page before repeating. [S3]
18 Warrants Why is a hosted Jupyter not the product? If the reconstructable unit is the recorded context, the IDE is a client of that unit. [S4] [S2]
19 Warrants Why is "any tool" not "no lock-in"? Exporting an artifact is not exporting Environments, hardware tiers, and the metadata stores. [S5] [S2]
20 Warrants What test would weaken both "Nexus replaces a lakehouse" and "one cluster is always enough"? Attach a second plane and publish an App there; record what the UI forbids. [S3]
